# 彩潮 · CHROMA TIDE — 美术圣经 v2.0
**水墨第一人称 / 纸本墨戏 · 锁定版**

> v2.0 为「半重做」后的唯一视觉来源：第一人称、水墨纸本、以打击感为核心。
> 任何单张资产、UI、特效、宣传图都按此执行，不临时改风格。

---

## 0. 项目假设（未指定处以此为准）

| 项 | 锁定值 |
|---|---|
| 类型 | 3D 第一人称割草肉鸽（近战三连斩 + 局内升级 + Boss） |
| 镜头 | 第一人称，眼高 1.64m，FOV 80°，跟随头部起伏/冲刺/受击 |
| 平台 | 手机竖屏 390×844 dp @2x 为主；桌面鼠标锁定；网页 + Android APK |
| 引擎 | Three.js r149，零构建，程序化几何 + 画布笔触 + 两张手绘 PNG（毛笔/图标） |
| 单局 | 6 分钟；3:00、6:00 两场 Boss；同屏敌人 ≤ 45 |
| 生产 | 1 人程序化资产；不做写实、不加滤镜、不用现成素材 |

**一句话**：世界是一张纸，敌人是纸上的墨；只有刀锋落下的地方，才短暂地长出颜色。

---

## 1. 四条铁律

1. **纸墨先行**：画面先读黑、白、灰三组价值；朱砂与石绿只做「事件色」，面积 ≤ 8%。
2. **打击感优先**：任何视觉都不能削弱「落刀—命中—反馈」的三段读秒。
3. **选择性着墨**：远处的山、竹、石只留剪影；细节只给敌人眼睛、刀锋、Boss 金裂、UI。
4. **第一人称构图**：屏幕下 1/3 是武器与手；中央 40% 必须留给敌人、准星与前摇；HUD 不压准星。

## 2. 锁定色板

### 2.1 纸与墨
| 名 | 色号 | 明度 | 用途 | 面积 |
|---|---|---|---|---|
| 纸 | `#EDE5D3` | 9.0 | 天空、纸面、UI 文字（深色底） | 35% |
| 纸阴 | `#D8CCB2` | 7.6 | 地面中间调、纸纹 | 20% |
| 淡墨 | `#8A8578` | 5.2 | 远山、纸纹、次要素描 | 15% |
| 中墨 | `#4A463F` | 3.0 | 近山、竹、石 | 12% |
| 浓墨 | `#14120F` | 0.8 | 敌人、笔锋、UI 边框、最深值 | 15% |

### 2.2 事件色（只给「发生的事」）
| 名 | 色号 | 用途 | 触发 |
|---|---|---|---|
| 朱砂 | `#B23A2A` | 日轮、命中、受伤、Boss 核心、封印 | 命中/受击/危险 |
| 石绿 | `#4E7A72` | 第二层颜色爆开、治疗边缘 | 击杀/升级 |
| 金 | `#C9A45C` | 笔杆金箍、Boss 金裂、UI 重点 | 奖励/弱点 |
| 纸白 | `#F4E9D2` | 刀光核心、命中闪白、文字高光 | 命中瞬间 |

**规则**
- 平时画面只有纸/墨/朱砂日轮；**颜色出现在命中点、击杀点、UI 重点**，6 秒内淡回墨色。
- 禁止大面积饱和色、彩虹渐变、彩色天空。
- 朱砂只给「危险/伤害/日轮/封印」，不做装饰。

### 2.3 明度阶梯
天空 9.0 → 远山 6.5–7.5 → 近山 4.0–5.0 → 地面 7.0–8.0 → 敌人 1.0–2.5 → 墨线 0.8。
敌人与地面至少差 **5 个明度级**，因此敌人天然读作黑影；靠金眼与纸边光定朝向。

## 3. 剪影与比例

### 3.1 第一人称屏幕读数
- 玩家武器：屏幕右下 30–38% 宽；笔头在 60–70% 高度，不压准星中心。
- 普通敌人：2–10m 处占屏高 18–45%；眼距 ≥ 18px（500px 宽基准）。
- Boss：5–14m 处占屏高 35–60%；必须有冠、肩刺、金核三处识别点。
- 敌人四型仍靠外轮廓区分：**圆团（墨蚜）/ 细长（疾笔）/ 宽梯形（砚龟）/ 高瘦（泼墨者）**。

### 3.2 比例（m）
| 对象 | 高 | 备注 |
|---|---|---|
| 玩家眼高 | 1.64 | 头部起伏 ±2.6cm |
| 墨蚜 | 1.3–1.7 | 群 |
| 疾笔 | 2.0 | 窄、快 |
| 砚龟 | 2.4 | 宽、慢 |
| 泼墨者 | 2.3 | 细、远程 |
| 墨渊巨像 | 5.2 | 冠 5.6、肩宽 4.5 |

- 第一人称不显示玩家身体；影子/受击/移动仍要让玩家知道自己站在纸上。
- 怪物朝向必须用金眼 + 口器 + 前倾表达；禁止「无脸黑块」。

## 5. 光照与构图

| 层 | 做法 |
|---|---|
| L1 主光 | 冷白纸光 `1.06,1.03,0.98`，方向 (-0.35,0.86,0.36)，只用于体积感 |
| L2 补光 | 冷灰 `0.40,0.42,0.44`，抬暗部，不投影 |
| L3 边光 | 纸白 Fresnel 0.35–0.55，只给敌人/毛笔/Boss |
| L4 事件光 | 朱砂/金自发光，只给眼睛、Boss 金核、命中火花，面积 ≤ 3% |
| L5 雾 | 纸色 `#E7DECB`，28m 起、145m 满；远山逐层变淡 |
| 天空 | 纸色纯底 + 朱砂日轮（直径约屏高 22%，位于上方 1/3） |

- 不使用真实阴影贴图；敌人与 Boss 用软墨影贴地。
- 构图：日轮在上 1/3；敌人/准星在中 1/3；毛笔/HUD 在下 1/3。
- 地面保留至少一条从左下到右上的大笔触，给第一人称空间感。

## 6. UI / 图标

- 三色：纸 `#EDE5D3`、墨 `#14120F`、朱砂 `#B23A2A`；金只给可充能/奖励。
- 形状：直角/微圆角纸片 + 1.5px 墨边 + 4px 内纸边；面板有纸纤维纹理。
- 字体：标题宋体 700，正文 PingFang SC；数字等宽。
- HUD：墨底纸字，HP 朱砂条，XP 金条；准星纸白描边墨；命中标记朱砂/金。
- 触控：攻击钮 ≥ 90dp，其余 ≥ 64dp；按钮不压准星；摇杆只占左 46%。
- 升级卡：纸面 + 墨边 + 左侧事件色条 + 48dp 墨图标 + 等级点。
- 图标：48 网格、2px 墨描边、2–4 个色块；不换透视、不换圆角。

## 7. 动效与打击感（核心）

### 7.1 一段攻击的读秒
| 阶段 | 时间 | 表现 |
|---|---|---|
| 输入 | 0ms | 武器下沉/后摆 6–10%，音效 whoosh 起 |
| 前摇 | 90–150ms | 笔锋后拉，准星周围轻微收束 |
| 命中 | +0~40ms | 顿帧 50–110ms + 镜头后坐 + FOV +5.5° + 屏幕斩弧 + 命中标记 |
| 余波 | 120–220ms | 敌人闪白/击退/硬直，墨点飞溅，屏幕墨渍淡出 |
| 收刀 | 180–260ms | 武器回位，允许输入下一段 |

- **三连斩**：斜斩（右→左）→ 反手（左→右）→ 突刺（前推）；第三下伤害 ×1.45、击退 8.5、顿帧更重。
- **重击「破」**：360° 旋身，0.32s 命中，击退 10，镜头滚转 0.06rad，顿帧 110ms。
- **闪**：0.18s 突进，FOV +7°，0.32s 无敌，残影/墨点拖尾。
- **万彩**：慢放 0.4s，朱砂/金/墨三层环，清场。

### 7.2 必须有的反馈层（缺一不可）
1. 顿帧（世界减速，UI/墨渍继续）。
2. 镜头后坐（pitch/yaw/roll）+ 位置后撤。
3. FOV 冲击。
4. 屏幕斩击弧（墨边 + 纸白核心）。
5. 命中标记（4 短划）+ 伤害数字（朱砂/墨，纸描边）。
6. 敌人闪白 60–90ms、击退、硬直。
7. 墨点/色点飞溅 + 地面墨渍。
8. 合成音效三层：whoosh、impact（低频+噪声）、kill（湿墨+纸裂）。
9. 击杀慢放 70ms；重击/多杀 110ms。
10. 手机震动 12–35ms。

### 7.3 禁止
- 只换颜色、只放符号、只飘一个数字当命中。
- 屏幕大面积泛光遮住敌人前摇。
- 顿帧超过 150ms 导致操作粘滞。
- 武器挡住准星或敌人。

## 9. 视觉错误清单

1. 把旧版彩墨/写实资产直接套水墨滤镜。
2. 纸面与敌人明度接近，靠描边硬救。
3. 全场彩色，没有「墨—纸—事件色」的层级。
4. 武器模型过大、挡准星、穿模。
5. 命中只有数字，没有顿帧/镜头/闪白/音效。
6. 敌人贴脸挡住镜头；必须保持 ≥ 2.15m。
7. 屏幕特效盖住 Boss 前摇、准星、攻击钮。
8. UI 用金属渐变、照片纹理、玻璃拟态。
9. 不同批次的图标圆角/描边/透视不一致。
10. 抄任何具体游戏的角色、Logo、构图或配色组合。
