## 0. 项目假设（先声明，再画）

| 项 | 锁定值 |
|---|---|
| 类型 | 3D 割草肉鸽（波次围杀 + 局内升级 + Boss 收尾） |
| 镜头 | **固定 3/4 俯视**，俯角 50°–54°，FOV 46°，跟随主角，无自由旋转 |
| 平台 | 手机竖屏 390×844 dp @2x 为主，桌面等比适配；网页 + Android APK |
| 引擎 | Three.js r149，纯静态零构建，程序化几何 + 顶点色 + 2 张程序化画布贴图 |
| 单局 | 6 分钟；3:00 中 Boss，6:00 终 Boss；同屏敌人 ≤ 160 |
| 生产 | 1 人程序化资产，无原画/建模/贴图库；**不做照片级写实，不做滤镜** |

**一句话**：荒原像一幅还没干透的油画，主角是画里唯一还在发光的笔触；
敌人是褪色的墨，被打碎时把颜色还给地面。

## 1. 视觉宣言与四条铁律

1. **体块先行**：40 px 高的剪影能认出「谁、朝哪、危不危险」。
2. **暖冷对撞**：暖金主光照亮战场，冷紫墨影吞掉敌人；禁止全屏同一色温。
3. **选择性细节**：只在脸、武器、危险前摇、拾取物上加细节，其余留大面。
4. **读数优先**：任何华丽都不能遮住敌人前摇、Boss 范围、拾取物与玩家位置。

**本作专属母题**：颜色即生命。玩家 → 暖白/朱红；敌人 → 冷紫/石板蓝；
击杀 → 颜料溅在地面短暂留色；受伤 → 屏幕边缘褪成灰紫。

## 3. 剪影与比例

### 3.1 俯视可读性（唯一检验）
- 玩家：**斗笠圆 + 双肩 + 环绕笔锋**，直径 ≥ 敌人 1.6 倍。
- 敌人四型必须靠外轮廓区分，不能靠颜色：
  - 墨蚜 = **水滴/圆团**（矮、圆、成群）
  - 疾笔 = **细长箭头**（尖、前倾、拖尾）
  - 砚龟 = **宽梯形**（宽肩、厚背、慢）
  - 泼墨者 = **高瘦棒棒糖**（细身 + 大头）
  - Boss = **三角山体 + 双臂**，是普通敌人的 3 倍高。
- 每型都有一个「记忆点」：墨蚜角、疾笔尾鳍、砚龟背纹、泼墨者墨囊、Boss 金裂。

### 3.2 比例（单位：米，玩家身高 1.8）
| 对象 | 高 | 宽 | 头身比 | 备注 |
|---|---|---|---|---|
| 玩家 | 1.80 | 0.95（含斗笠） | 5.8 头 | 手/武器放大 1.2× |
| 墨蚜 | 0.75 | 0.70 | 2 头 | 圆 |
| 疾笔 | 1.10 | 0.55 | 3 头 | 尖 |
| 砚龟 | 1.35 | 1.30 | 3 头 | 宽 |
| 泼墨者 | 1.65 | 0.75 | 4 头 | 细 |
| Boss | 4.6 | 3.6 | 3.5 头 | 压迫感 |

- 屏幕占比（390×844）：玩家 **10–12% 屏高**（85–100 px）；小怪 4–7%；
  Boss **28–34%**；Boss 血条与预警圈永远不被特效遮挡。
- 头顶高度统一：小怪特效/伤害数字在 1.2 m 处，玩家 2.1 m，Boss 5.2 m。

### 3.3 选择性简化
| 保留 | 删除 |
|---|---|
| 朝向（眼睛/角/尾）、武器轮廓、前摇动作 | 手指、衣褶、发丝、牙齿 |
| 敌人 1 个形状记忆点 | 逐片鳞甲、逐块砖 |
| 地面 2–3 种大笔触 + 墨池 | 草叶个体（用 5 刀片/簇概括） |

## 4. 材质语言（2–3 色块 + 1 条边光 + 0 高光点）

| 材质 | 做法 | 禁止 |
|---|---|---|
| 布/袍 | 顶亮、中调、底冷三阶；下摆压暗 | 布纹贴图、法线 |
| 皮肤/脸 | 2 阶；脸颊一点暖 | 毛孔、油光 |
| 斗笠/木 | 亮金 + 中陶 + 深褐缘 | 木纹照片 |
| 石/砚 | 5–7 面，亮面大、暗面切一刀；苔绿点 1 处 | 写实岩石贴图 |
| 墨体（敌） | 体块 + 冷紫边光 + 金眼；表面无高光 | 湿润镜面、次表面散射 |
| 笔锋/金属 | 2 阶 + 1 条金边；不反射环境 | 金属度/环境贴图 |
| 地面 | 程序化大笔触（暖土/草/冷影），墨池为静态暗紫斑 | 噪点滤镜、照片地面 |
| 特效 | 元素色 + 白核 + 墨边，≤3 色；软圆笔触贴图 | 5 色以上、大面积泛光 |

**手绘感来源**（必须）：
1. 明暗交界被低频噪声**轻微打散**（±3–8% 阈值），不是全屏噪点；
2. 顶点色 ±3% 抖动，让色块边缘不齐；
3. 笔触方向性：地面长弧、布料竖向、墨迹向外溅；
4. 无高光点、无环境反射、无 PBR 贴图。

## 5. 光照层级

| 层 | 内容 | 参数/约束 |
|---|---|---|
| L1 主光 | 暖阳 `#FFD7A6`，方向 (−0.55, 0.78, 0.32) | 只 1 盏；俯角 45°–55° |
| L2 补光 | 冷天 `#86B7C9`，半球式 | 强度 ≈ 主光 35%；抬暗部 |
| L3 边光 | 金 `#FFC97E`，Fresnel 2.6 次方 | 只给角色/敌人；1–2 px 感 |
| L4 自发光 | 金眼、Boss 金裂、拾取物 | 面积 ≤ 屏幕 3% |
| L5 接触影 | 软圆墨影贴片（非阴影贴图） | 不透明度 0.45；半径 = 体型 × 1.1 |
| 雾 | 冷夜 `#26313A`，48 m 起、92 m 满 | 压远景、藏边界 |

- **不启用真实阴影贴图**；不用 bloom 全屏泛光；不用环境反射。
- 战斗亮度可读：玩家周围 6 m 内的地面必须比 12 m 外亮 1 级（靠地面贴图与雾实现）。

## 6. UI / 图标

### 6.1 语法
- 三色：墨底 `#1A1714`（85% 不透明）+ 纸字 `#F2E8D5` + 金强调 `#E8BE74`；
  技能色只用于图标与关键词：笔锋=朱、墨爆=暖陶、雷链=天、墨雨=洋红、治疗=玫。
- 形状：圆角 14–18 dp、2 px 墨边、1 层 3 dp 软影；**严禁**金属渐变/照片纹理。
- 字体：标题宋体（Songti SC 700），正文 PingFang SC；数字用等宽数字（`font-variant-numeric: tabular-nums`）。
- 卡面：墨底 + 顶部 3 px 技能色条 + 48 dp 图标 + 标题 + 2 行说明 + 等级点。

### 6.2 尺寸与触控（390×844 基准）
| 项 | 规格 |
|---|---|
| 正文 | ≥ 13 px；说明 ≥ 11 px；标题 20–30 px |
| 对比 | 正文 ≥ 4.5:1；大字 ≥ 3:1 |
| 触控目标 | ≥ 48×48 dp；主按钮 ≥ 56 dp；摇杆热区 ≥ 屏宽 60% |
| 安全区 | 顶部 HUD ≤ 96 px；底部按钮距边 ≥ 24 px + safe-area |
| 遮挡 | 升级面板打开即暂停；Boss 血条不与 HUD 重叠；按钮不压摇杆 |
| 图标网格 | 48 dp 画布，内容 36 dp，2 px 描边，2–4 个色块 |

### 6.3 状态语义
- 可用 = 满亮 + 金边；冷却 = 压暗 45% + 环形进度；危险 = 朱色呼吸；奖励 = 金。
- 不加假排行榜、假账号、假在线人数。

## 7. 动效准则

**先读剪影，再读方向，最后读细节。**

| 动作 | 时长 | 关键 |
|---|---|---|
| 待机 | 2.4 s 循环 | 呼吸 ±2 cm、斗笠轻微摆 |
| 跑动 | 0.45 s 循环 | 身体前倾 6°、上下浮 4 cm、袍摆滞后 |
| 笔锋命中 | 0.12 s | 闪白 60 ms + 击退 0.25 m + 火花；**不打断敌人轮廓** |
| 受伤 | 0.15 s | 后仰 + 屏幕边缘灰紫 + 震屏 6 px + 红字 |
| 冲刺 | 0.22 s | 压扁→拉伸，3 个残影，无敌 0.25 s |
| 墨爆 | 0.45 s | 0.1 s 聚气 → 环扩散 0.35 s；击退 1.2 m |
| 雷链 | 0.2 s | 0.05 s 闪白竖雷 → 0.15 s 余辉；链间 30 ms 延迟 |
| 墨雨 | 0.5 s | 空中拖尾 → 砸地溅射；落点先有 0.15 s 暗斑 |
| 升级 | 0.35 s | 卡牌上浮 12 px + 金光扫过 |
| 大招「万彩归一」 | 1.1 s | 慢放 0.25 s + 3 层色环 + 全屏去灰；结束回正 |
| Boss 前摇 | 0.9 s | 地面朱紫圈由大收小 + 体块金裂变亮；**必须可读** |
| 死亡 | 0.8 s | 敌人先塌陷再溅色；玩家跪地 + 世界褪色 |

- 所有受击/命中必须有「过程」：起势 → 爆发 → 余波，不允许只换颜色。
- 顿帧：重击 40–60 ms，大招 120 ms；顿帧期间特效继续但不推进 AI。
- 同屏粒子 ≤ 500；单次爆发 ≤ 80；防止糊屏。

## 10. 视觉错误清单（DO NOT）

1. 给写实模型套「油画滤镜」或全屏噪点冒充手绘。
2. 同一画面混用写实材质与卡通材质；敌人一部分高光、一部分平涂。
3. 全屏同一色温，或把饱和度拉满当风格。
4. 用 PBR 高光/反射/法线贴图制造「精致感」。
5. 敌人与地面明度接近，只能靠描边硬救。
6. 特效 5 种以上颜色、大面积泛光挡住 Boss 前摇和敌人轮廓。
7. 逐片叶子、逐块砖、逐根发丝建模。
8. UI 用照片纹理、金属渐变、真实投影；不同批次图标圆角/描边不一致。
9. 为「华丽」牺牲移动端帧率：粒子/敌人超预算、DPR 不设上限。
10. 抄某款游戏的角色轮廓、Logo、构图或配色组合。
